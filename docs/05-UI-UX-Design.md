# وثيقة التصميم الهندسي لمشروع Remoo Download
## الفصل 5: تصميم واجهة المستخدم (UI/UX)

**رقم الوثيقة:** SDS-05
**يعتمد على:** SDS-01، SDS-02، SDS-03، SDS-04

---

## 5.1 مبادئ التصميم

1. **الوضوح أولاً:** كل معلومة عن حالة التحميل يجب أن تكون مرئية فوراً.
2. **الاستجابة:** الواجهة يجب أن تبقى مستجيبة حتى أثناء تحميلات ثقيلة (استخدام threading منفصل لعمليات التحميل).
3. **الوصولية:** دعم لوحة المفاتيح بالكامل، أحجام خطوط قابلة للتعديل، تباين لوني مناسب.
4. **الاتساق:** تصميم موحد عبر كل الحوارات والنوافذ.
5. **اللغة العربية أولاً:** واجهة RTL كاملة مع دعم كامل للنص العربي.

تبويبات:

- **الإشعارات:** نوع الإشعارات، وضع الصمت
- **المظهر:** الثيم (Dark/Light/Custom QSS)

## 5.3 مكونات الواجهة التفصيلية

### 5.3.1 قائمة التحميلات (Download List)

- **العرض:** جدول مع أعمدة قابلة لإعادة الترتيب والعرض/الإخفاء.
- **الأعمدة الافتراضية:**
  1. حالة (أيقونة: متوقف، جاري، منتهي، فاشل)
  2. اسم الملف
  3. الحجم (المحمّل / الكلي)
  4. شريط التقدم (عمود مرئي)
  5. السرعة الحالية
  6. الوقت المتبقي
  7. الأولوية
  8. الفئة
- **التفاعل:**
  - نقرة مزدوجة → حوار الخصائص
  - سحب وإفلات لإعادة الترتيب (تغيير الأولوية)
  - قائمة سياقية (إيقاف/استئناف/إلغاء/فتح المجلد/نسخ الرابط)
  - تحديث فوري كل ثانية

### 5.3.2 رسم بياني للسرعة (Speed Graph)

- **النوع:** خط زمني (Line Chart)
- **المحور الأفقي:** الوقت (آخر 5 دقائق افتراضيًا)
- **المحور العمودي:** السرعة (MB/s)
- **الألوان:** منحنى التحميل الحالي + منحنى المتوسط
- **التصدير:** زر تصدير البيانات كملف CSV
- **التكبير:** إمكانية تحديد منطقة للتكبير

### 5.3.3 شريط النظام (System Tray)

- **أيقونة:** تغيّر حسب الحالة (أساسي = أخضر، نشط = أزرق، فارغ = رمادي)
- **القائمة السياقية:**
  - فتح Remoo Download
  - إيقاف الكل / استئناف الكل
  - فتح مجلد التحميلات
  - إعدادات
  - خروج
- **الإشعارات:** إشعارات نظام أصلية عند اكتمال تحميل أو فشله

### 5.3.4 الإشعارات (Notifications)

- **عند اكتمال التحميل:** إشعار نظامي "تم تحميل: filename.mp4" مع زر "فتح المجلد"
- **عند فشل التحميل:** إشعار "فشل تحميل: filename.mp4" مع زر "إعادة المحاولة"
- **عند انقطاع الشبكة:** إشعار "انقطاع الاتصال — جاري إعادة المحاولة"
- **عند عودة الشبكة:** إشعار "عاد الاتصال — جاري استئناف التحميلات"

## 5.4 التصميم الداكن والفاتح (Dark/Light Theme)

### 5.4.1 الثيم الافتراضي
- **الداكن (Dark):** الافتراضي. ألوان داكنة مع تباين عالٍ.
- **الفاتح (Light):** ألوان فاتحة مناسبة للعمل نهارًا.
- **المخصص (Custom):** المستخدم يختار ملف QSS مخصص.

### 5.4.2 نظام الألوان

| العنصر | Dark | Light |
|---|---|---|
| خلفية أساسية | #1e1e1e | #ffffff |
| خلفية بديلة | #2d2d2d | #f0f0f0 |
| نص أساسي | #e0e0e0 | #333333 |
| نص ثانوي | #a0a0a0 | #666666 |
| لون التقدم | #4caf50 | #2196f3 |
| لون التحذير | #ff9800 | #ff9800 |
| لون الخطأ | #f44336 | #f44336 |
| رابط | #64b5f6 | #1565c0 |

### 5.4.3 QSS (Qt Style Sheets)

- الثيمات مخزنة كملفات `.qss` في مجلد `resources/themes/`
- دعم التبديل الفوري بدون إعادة تشغيل التطبيق
- إمكانية إنشاء ثيمات مخصصة عبر ملف QSS مع متغيرات CSS محددة مسبقًا

## 5.5 التصميم المتجاوب (Responsive Design)

- النافذة الرئيسية قابلة لتغيير الحجم مع حد أدنى 600×400 بكسل.
- قائمة التحميلات تتكيف مع حجم النافذة (إخفاء أعمدة أقل عند الضيقة).
- الرسم البياني للسرعة يتكيف مع المساحة المتاحة.
- على الشاشات الصغيرة، يتم طي الأعمدة الأقل أهمية تلقائيًا.

---

## 5.6 التفاعلات الرئيسية (Key Interactions)

| الإجراء | التفاعل |
|---|---|
| نسخ رابط تحميل | إشعار في شريط النظام "رابط جديد — هل تريد تحميله؟" |
| النقر على رابط تحميل في المتصفح | نافذة Remoo Download تظهر تلقائيًا مع حوار إضافة الرابط |
| إيقاف تحميل | ينتقل لحالة "مؤقت" مع حفظ نقطة تحقق فورية |
| استئناف تحميل | يبدأ من آخر بايت مكتمل مع عرض التقدم |
| إلغاء تحميل | يُحذف الجزء المؤقت ويُزال من القائمة |
| اكتمال التحميل | إشعار نظامي + تحديث القائمة + إجراء ما بعد الانتهاء |
| سحب رابط من المتصفح إلى النافذة | إضافة رابط جديد تلقائيًا |

## 5.7 الترجمة (Localization)

- **اللغة الافتراضية:** العربية (RTL)
- **اللغة الثانية:** الإنجليزية (LTR)
- **نظام الترجمة:** ملفات `.ts` من Qt Linguist
- **دعم المجتمع:** سهولة إضافة ترجمات جديدة عبر GitHub
- **الاتجاه:** دعم RTL كامل (محاذاة يمينى، أيقونات ممرّعة)
