## 📝 خطوات التحقق التالية (أنت شخصيًا)

### 1. بناء المشروع
```cmd
cmake --preset mingw-debug -DBUILD_CLI=ON -DBUILD_TESTS=ON
cmake --build --preset mingw-debug
```

### 2. تشغيل الاختبارات الآلية
```cmd
cd build
.\bin\remo_tests.exe
```
**توقع:** جميع الاختبارات تنجح

### 3. تشغيل الخدمة
```powershell
.\build\bin\remo_service.exe
```
**اترك هذا Terminal مفتوحًا**

### 4. اختبار CLI (baseline)
في terminal آخر:
```powershell
.\build\bin\remo_cli_client.exe add-download "https://proof.ovh.net/files/10Mb.dat" -d "D:\TestDownloads"
```

### 5. التحقق من الملف
```powershell
Get-ChildItem "D:\TestDownloads" | Select-Object Name, Length
```
**توقع:** `10Mb.dat` بحجم 10,485,760 bytes

### 6. تسجيل Native Host
```powershell
powershell -ExecutionPolicy Bypass -File tools\register_native_host.ps1
```

### 7. تحميل الإضافة في Chrome
1. افتح `chrome://extensions`
2. فعّل Developer Mode
3. اضغط "Load unpacked"
4. اختر `extensions\chromium`
5. انسخ Extension ID

### 8. إعادة التسجيل بـ ID الحقيقي
```powershell
powershell -ExecutionPolicy Bypass -File tools\register_native_host.ps1 -ExtensionId "YOUR_EXTENSION_ID"
```

### 9. أعد تشغيل Chrome

### 10. اختبار من البداية للنهاية
1. افتح `https://proof.ovh.net/files/`
2. اضغط على `10Mb.dat`
3. **توقع:**
   - تحميل المتصفح يختفي (ملغي)
   - إشعار Chrome: "Download Started"
   - الملف يظهر في `D:\BrowserDownloads`
   - حجم الملف يكبر تدريجيًا حتى 10MB

### 11. التحقق النهائي
```powershell
Get-ChildItem "D:\BrowserDownloads\10Mb.dat" | Select-Object FullName, Length
```
**توقع:** الملف موجود بالحجم الصحيح تمامًا (10,485,760 bytes)
