## 8.5 ملخص الأولويات

### v1.0 (Must-have) — الإصدار الأولي المستقر
- المحرك الأساسي للتحميل (متعدد الاتصالات + استئناف + إعادة اتصال)
- قائمة الانتظار بال أولويات
- الجدولة الأساسية
- الفئات والتنظيم التلقائي
- التكامل مع المتصفح (Native Messaging + WebExtension)
- الواجهة الأساسية (نافذة رئيسية + Tray + إشعارات)
- دعم HTTP/HTTPS
- الثيم + RTL عربي

### v1.x (Should-have) — تحسينات وإضافات
- محدد سرعة متعدد المستويات
- التقاط الفيديو (HLS/DASH)
- مراقبة الحافظة
- التحقق من سلامة الملف
- FTP/FTPS
- جدولة متكررة ووضع الهدوء
- سجل السرعة التاريخي

### v2.0+ (Nice-to-have) — ميزات متقدمة
- BitTorrent
- Site Grabber
- تطبيق موبايل
- دعم Linux الرسمي
- فحص الفيروسات
- CLI و Web UI
