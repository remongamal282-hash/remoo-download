# v0.5 Manual Verification Guide

This document provides step-by-step instructions for manually verifying that the v0.5 Native Messaging Host and Browser Extension integration works correctly.

## Prerequisites

Before starting verification, ensure you have:
- Built the project successfully (including `remo_native_host.exe`, `remo_service.exe`, and `remo_cli_client.exe`)
- Chrome or Edge browser installed
- PowerShell access

## Verification Roadmap

1. **Automated Tests** (runs first to catch basic issues)
2. **Manual Integration Test** (verify the full chain works)
3. **Browser Extension Test** (end-to-end user experience)

---

## Part 2: Manual Integration Test

This verifies the complete chain: Browser Extension → Native Host → IPC → Service → Download Engine → File on Disk

### Step 2.1: Start remo_service

Open a PowerShell terminal:

```powershell
cd d:\remoo-download\build\bin
.\remo_service.exe
```

**Expected Output:**
```
[remo_service] Starting on pipe: \\.\pipe\remo_download_ipc
[remo_service] IPC server started successfully
[remo_service] Service is ready and waiting for connections...
```

**✓ VERIFICATION:** Service starts without errors and shows "waiting for connections"

⚠️ **Keep this terminal open** - the service needs to run in the background.

### Step 2.2: Test CLI Client (Baseline Verification)

Open a **second** PowerShell terminal:

```powershell
cd d:\remoo-download\build\bin
.\remo_cli_client.exe add-download "https://proof.ovh.net/files/10Mb.dat" -d "D:\TestDownloads"
```

**Expected Output:**
```
[remo_cli_client] Connecting to IPC pipe \\.\pipe\remo_download_ipc...
[remo_cli_client Request]  {"command":"addDownload","url":"https://proof.ovh.net/files/10Mb.dat","savePath":"D:\\TestDownloads",...}
[remo_cli_client Response] {"ok":true,"status":"accepted","downloadId":1}
```

**✓ VERIFICATION:** 
- Client connects successfully
- Response contains `"ok":true`
- Check the service terminal - it should show activity

### Step 2.3: Verify File is Downloading

In the **second** terminal, run this every few seconds:

```powershell
# Windows PowerShell
Get-ChildItem "D:\TestDownloads" | Select-Object Name, Length
```

**Expected Output:**
```
Name        Length
----        ------
10Mb.dat    2458624    # Growing size
10Mb.dat    5242880    # Still growing
10Mb.dat    10485760   # Final size (10MB)
```

**✓ VERIFICATION:** File exists and grows to final size (10,485,760 bytes for 10Mb.dat)

## Part 4: Browser Extension Loading

### Step 4.1: Load Extension in Chrome

1. Open Chrome and navigate to: `chrome://extensions`
2. Enable **Developer mode** (toggle in top-right corner)
3. Click **Load unpacked**
4. Navigate to and select: `d:\remoo-download\extensions\chromium`
5. Click **Select Folder**

**Expected Result:**
- Extension appears in the list
- No errors shown
- Extension has a unique ID (e.g., `abcdefghijklmnopqrstuvwxyzabcdef`)

**✓ VERIFICATION:** Extension loads without errors.

### Step 4.2: Copy Extension ID

**IMPORTANT:** Copy the extension ID from the extensions page.

Example: `abcdefghijklmnopqrstuvwxyzabcdef`

### Step 4.3: Re-register with Real Extension ID

In PowerShell:

```powershell
cd d:\remoo-download
powershell -ExecutionPolicy Bypass -File tools\register_native_host.ps1 -ExtensionId "abcdefghijklmnopqrstuvwxyzabcdef"
```

Replace `abcdefghijklmnopqrstuvwxyzabcdef` with your actual extension ID.

**✓ VERIFICATION:** Re-registration completes successfully.

### Step 4.4: Restart Browser

**Close Chrome completely** and reopen it. This ensures the browser picks up the updated native messaging host registration.

## Part 6: End-to-End Download Test (Critical!)

This is the **most important test** - it verifies the complete chain works from browser click to file on disk.

### Step 6.1: Ensure Service is Running

Check the PowerShell terminal running `remo_service.exe` - it should still be running.

### Step 6.2: Create a Test Download Directory

```powershell
New-Item -ItemType Directory -Force -Path "D:\BrowserDownloads"
```

### Step 6.3: Navigate to Test URL

In Chrome, open this URL in a new tab:

```
https://proof.ovh.net/files/
```

This is a test file server with files of various sizes.

### Step 6.4: Initiate Download

**Method 1: Direct Click**
1. Click on **10Mb.dat** link
2. Watch the browser download tray

**Method 2: Context Menu**
1. Right-click on **10Mb.dat** link
2. Select "Download with Remoo Download"

**Expected Behavior:**
- Browser download starts briefly, then disappears (cancelled by extension)
- Chrome notification appears: "Download Started - Remoo Download is handling this file"
- Service terminal shows: `[remo_service] Received request: addDownload...`

**✓ VERIFICATION:** 
- Browser download is intercepted
- Notification appears
- Service logs the request

### Step 6.5: Monitor File Download

Open PowerShell and run this command repeatedly:

```powershell
# Run this every 2-3 seconds
Get-ChildItem "D:\BrowserDownloads" -Recurse | Where-Object { $_.Name -like "*.dat" } | Select-Object FullName, Length, LastWriteTime
```

**Expected Output:**
```
FullName                              Length    LastWriteTime
--------                              ------    -------------
D:\BrowserDownloads\10Mb.dat          1048576   2025-01-15 10:23:45  # Growing
D:\BrowserDownloads\10Mb.dat          5242880   2025-01-15 10:23:47  # Still growing
D:\BrowserDownloads\10Mb.dat          10485760  2025-01-15 10:23:50  # Complete!
```

**✓ VERIFICATION:** 
- File appears in download directory
- File size grows progressively
- Final size matches expected size (10,485,760 bytes for 10Mb.dat)

### Step 6.6: Verify File Integrity

```powershell
# Check file size
(Get-Item "D:\BrowserDownloads\10Mb.dat").Length

# Expected: 10485760 (exactly 10MB)
```

**✓ VERIFICATION:** File size is exactly correct.

## Troubleshooting

### Issue: Extension shows "Disconnected"

**Solutions:**
1. Verify `remo_service.exe` is running
2. Check that native host is registered: Run registry check command from Step 3.2
3. Verify manifest path is correct and `remo_native_host.exe` exists
4. Restart browser completely

### Issue: "Specified native messaging host not found"

**Solutions:**
1. Re-run `register_native_host.ps1` with correct extension ID
2. Verify registry entry exists
3. Check manifest file path is absolute and valid
4. Restart browser

### Issue: Downloads not intercepted

**Solutions:**
1. Check extension popup - is interception enabled?
2. Verify file meets size threshold (default: 10 MB)
3. Verify file extension is in configured list
4. Check browser console (F12) for JavaScript errors
5. Verify extension has necessary permissions

### Issue: File not appearing on disk

**Solutions:**
1. Check service terminal for errors
2. Verify save path exists and is writable
3. Check disk space
4. Verify URL is accessible (try in curl/wget)

### Issue: Build errors with tests

**Solutions:**
1. Ensure `-DBUILD_TESTS=ON` flag is set
2. Verify GTest is installed via vcpkg
3. Clean and rebuild: `cmake --build --preset mingw-debug --clean-first`
