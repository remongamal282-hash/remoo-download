# Remo Download UML Diagrams

This folder contains the executable Mermaid sources for SDS-06.

Each `.mmd` file can be previewed by Mermaid-aware Markdown tools, VS Code extensions,
GitHub renderers, or exported with Mermaid CLI.

## Diagram Index

- `01-core-download-engine-class.mmd` - core download engine classes
- `02-service-layer-class.mmd` - service orchestration classes
- `03-browser-add-download-sequence.mmd` - browser-to-download flow
- `04-pause-resume-sequence.mmd` - pause and resume flow
- `05-auto-reconnect-sequence.mmd` - automatic reconnect flow
- `06-download-lifecycle-state.mmd` - download lifecycle state machine
- `07-scheduler-tick-sequence.mmd` - scheduler tick flow
- `08-deployment-components.mmd` - deployment component overview
- `09-package-overview.mmd` - package/module overview
