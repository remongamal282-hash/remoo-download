# وثيقة التصميم الهندسي لمشروع Remoo Download
## الفصل 5: تصميم واجهة المستخدم (UI/UX Design)

**رقم الوثيقة:** SDS-05
**يعتمد على:** SDS-01, SDS-02, SDS-03
**التقنية:** Qt6 Widgets (سطح المكتب) + WebExtension UI (المتصفح)

---

## 5.1 مبادئ التصميم (Design Principles)

1. **الوضوح قبل الزخرفة:** المستخدم يجب أن يفهم حالة كل تحميل (جاري/متوقف/فشل) خلال أقل من ثانية بمجرد النظر للقائمة، دون الحاجة لفتح تفاصيل.
2. **دعم RTL كمواطن من الدرجة الأولى (First-class citizen):** بما أن العربية هي اللغة الأساسية الأولى للمشروع (2.7)، التصميم يُبنى من البداية بتخطيط يدعم الاتجاهين (RTL/LTR) عبر `QApplication::setLayoutDirection()` الديناميكي، وليس كترجمة نصوص فقط فوق تخطيط LTR ثابت.
3. **أقل عدد نقرات للمهام الشائعة:** إضافة تحميل جديد، إيقاف الكل، فتح مجلد التحميلات — كلها يجب أن تكون متاحة في نقرة أو نقرتين من أي شاشة.
4. **تناسق مع النظام (Native Feel):** استخدام مكونات Qt القياسية والالتزام بإرشادات كل نظام (Windows: زوايا وتباعد متوافقة مع Fluent؛ macOS: احترام تصرفات القوائم وMenu Bar المعتادة) بدل واجهة مخصصة تمامًا تبدو غريبة عن النظام.
5. **إتاحة (Accessibility):** دعم التنقل بلوحة المفاتيح بالكامل، تباين ألوان كافٍ (WCAG AA كحد أدنى)، وحجم خط قابل للتكبير من الإعدادات.

### 5.2.2 الطباعة (Typography)

| العنصر | الخط المقترح | الحجم |
|---|---|---|
| نص عربي | **Cairo** أو **IBM Plex Sans Arabic** (مفتوحة المصدر) | 14px أساسي |
| نص إنجليزي/لاتيني | **Inter** (مفتوحة المصدر) | 14px أساسي |

### 5.2.3 وحدات القياس والتباعد
- شبكة تباعد أساسية 8px (Spacing Grid): كل الهوامش والمسافات مضاعفات لـ 8 (8, 16, 24, 32...).
- زوايا مستديرة موحدة: 6px للأزرار والحقول، 10px للبطاقات/النوافذ الحوارية.

├── قائمة التحميلات (Download List) - الجزء الأكبر من الشاشة

### 5.4.2 نافذة إضافة تحميل جديد (Add Download Dialog)

**الحقول:**
- الرابط (URL) — إلزامي، مع زر "لصق من الحافظة".
- اسم الملف — يُملأ تلقائيًا من الرابط، قابل للتعديل.
- الفئة — قائمة منسدلة (تُقترح تلقائيًا حسب امتداد الملف، قابلة للتغيير يدويًا).
- مسار الحفظ — يتبع الفئة افتراضيًا، قابل للتخصيص لهذا التحميل تحديدًا.
- خيارات متقدمة (قابلة للطي/Collapsible):
  - عدد الاتصالات لهذا التحميل تحديدًا (Override للإعداد العام).
  - بدء فوري / إضافة للطابور فقط.
  - جدولة وقت البدء.
  - بيانات مصادقة (اسم مستخدم/كلمة مرور) إن كان الموقع يتطلبها.

**معاينة قبل التحميل:** فحص HEAD تلقائي في الخلفية بمجرد لصق الرابط، يعرض حجم الملف المتوقع ونوعه قبل الضغط على "بدء" — يمنع مفاجآت لاحقة (مثل تحميل ملف HTML صفحة خطأ بدل الملف الفعلي).

---

### 5.4.3 نافذة خصائص التحميل (Download Properties)

تبويبات:
1. **عام:** الرابط، الحجم، الحالة، عدد الأجزاء وحالة كل جزء (جدول segments مصغر ومرئي).
2. **الأداء:** رسم بياني حي لسرعة التحميل عبر الوقت (2.7 - Speed Graph)، مع إمكانية تصدير CSV.
3. **السجل:** كل الأحداث المرتبطة بهذا التحميل من جدول `download_events` (متى بدأ، متى توقف، محاولات إعادة الاتصال).
4. **السلامة:** نتيجة Checksum (متطابق ✔ / غير متطابق ✘ / لم يُحسب).

### 5.4.4 نافذة الإعدادات (Settings)

تبويبات جانبية:

| التبويب | المحتوى |
|---|---|
| **عام** | اللغة، بدء التشغيل مع النظام، السلوك عند الإغلاق (تصغير للـ Tray أو إغلاق فعلي) |
| **التحميل** | عدد التحميلات المتزامنة، عدد الاتصالات الافتراضي لكل ملف، إعادة المحاولة (الحد الأقصى، الفاصل الزمني) |
| **السرعة** | الحد العام، الجدولة الزمنية للسرعة (2.2.4) |
| **الفئات** | إدارة الفئات وقواعد المطابقة (يفتح Category Manager) |
| **الجدولة** | إدارة الجداول المتكررة ووضع الهدوء (2.3.2) |
| **المتصفح** | حالة اتصال كل متصفح، تفعيل/تعطيل الاعتراض التلقائي، فلاتر الحجم/الامتداد (2.4.1) |
| **الإشعارات** | تفعيل/تعطيل الصوت، الإشعارات الأصلية، مراقبة الحافظة (2.4.3) |
| **المظهر** | فاتح/داكن/تلقائي (حسب النظام)، حجم الخط |
| **متقدم** | مسار قاعدة البيانات، مستوى السجلات (Logs)، إدارة الإضافات (Plugins) |

### 5.4.5 إدارة الفئات (Category Manager)

جدول قابل للتعديل مباشرة (Inline editing): اسم الفئة | قاعدة المطابقة (Regex) | المسار الافتراضي | فئة أب (Parent). زر "+" لإضافة فئة فرعية جديدة، مع معاينة حية لعدد الملفات التي ستُطابق القاعدة المُدخلة (Test Regex Live Preview) لتفادي أخطاء الصياغة.

---

### 5.4.6 أيقونة شريط النظام (System Tray / Menu Bar)

- **أيقونة ديناميكية:** تتغير بصريًا حسب الحالة العامة (نشطة/خاملة/فيها أخطاء) — مؤشر سريع دون فتح النافذة.
- **قائمة سريعة عند النقر الأيمن:** إيقاف الكل، استئناف الكل، فتح النافذة الرئيسية، فتح مجلد التحميلات الأخير، خروج من البرنامج.
- **Tooltip عند التحويم:** ملخص سريع ("3 تحميلات نشطة - 4.5MB/s").

## 5.5 واجهة إضافة المتصفح

### 5.5.1 نافذة Popup الصغيرة
تظهر عند الضغط على أيقونة الإضافة في شريط أدوات المتصفح:
```
┌─────────────────────────┐
│  🟢 متصل بـ Remoo Download │
├─────────────────────────┤
│  اعتراض التحميلات   [●─] │
│  التقاط الفيديو      [●─] │
│  مراقبة الحافظة      [─●] │
├─────────────────────────┤
│  فتح Remoo Download →     │
└─────────────────────────┘
```
- حالة الاتصال بالتطبيق الرئيسي واضحة فورًا (متصل 🟢 / غير متصل 🔴 مع رابط "تثبيت/تشغيل التطبيق").
- مفاتيح تبديل (Toggles) سريعة للإعدادات الأكثر استخدامًا دون الحاجة لفتح التطبيق الكامل.

### 5.5.2 الزر العائم فوق الفيديو (Video Grabber Overlay - 2.4.2)
أيقونة تحميل صغيرة شبه شفافة تظهر في الزاوية العلوية لأي عنصر `<video>` مكتشف عند التحويم عليه، تتحول لقائمة اختيار الجودة عند الضغط لو توفرت أكثر من جودة، دون حجب المحتوى الأساسي للصفحة.

## 5.6 التفاعلات الحرجة (Critical User Flows)

### 5.6.1 تدفق: من رابط في المتصفح إلى تحميل مكتمل (تجربة المستخدم)
1. المستخدم يضغط رابط تحميل → **إشعار خفيف (Toast)** يظهر لثانيتين: "بدأ التحميل عبر Remoo Download" (بدون مقاطعة تصفحه بنافذة منبثقة كبيرة، إلا لو فعّل خيار "اسألني في كل مرة" من الإعدادات).
2. لو الملف يحتاج تأكيد (مثلًا أكبر من حد معين محدد بالإعدادات)، تظهر نافذة "إضافة تحميل جديد" (5.4.2) مباشرة.
3. عند الاكتمال: إشعار نظام أصلي مع زرين سريعين: "فتح الملف" و"فتح المجلد".

### 5.6.2 تدفق: التعامل مع فشل الشبكة أثناء التحميل (مرتبط بـ 2.2.3)
1. الصف في القائمة الرئيسية يتحول للون الأصفر تلقائيًا، والحالة تتغير لـ "إعادة الاتصال (محاولة 2)".
2. لا نافذة منبثقة مزعجة — فقط تحديث بصري هادئ في الصف نفسه + تحديث الأيقونة في الـ Tray.
3. لو تجاوزت المحاولات الحد الأقصى (`max_retries`)، الحالة تتحول لـ "فشل" (أحمر) + إشعار نظام واحد فقط (لا تكرار إشعارات لكل محاولة فاشلة — تفاديًا لإرهاق المستخدم).

## 5.7 إتاحة الوصول (Accessibility Checklist)

- [ ] كل عنصر تفاعلي قابل للوصول بلوحة المفاتيح (Tab order منطقي).
- [ ] اختصارات لوحة مفاتيح للإجراءات الشائعة (مثال: `Ctrl+N` لإضافة تحميل، `Space` لإيقاف/استئناف المحدد).
- [ ] تباين ألوان يحقق WCAG AA (نسبة 4.5:1 كحد أدنى للنص العادي).
- [ ] دعم قارئ الشاشة عبر `QAccessible` (أسماء وأدوار واضحة لكل عنصر Qt).
- [ ] عدم الاعتماد على اللون وحده لنقل المعلومة (كل حالة لها أيضًا نص/أيقونة، وليس اللون فقط).

## 5.8 ملاحظات التسليم لأداة الذكاء الاصطناعي عند التنفيذ

- تُبنى الواجهة بـ Qt Widgets (وليس QML) لسهولة الصيانة بلغة C++ مباشرة دون طبقة QML/JS إضافية، إلا إذا احتاج فريق التطوير لاحقًا رسومًا متحركة معقدة تبرر QML.
- كل شاشة تُبنى كـ Widget/Dialog منفصل في ملف مستقل ضمن `gui/` (كما في هيكلة الفصل 3)، مع ملفات `.ui` (Qt Designer) حيثما كان التخطيط الثابت مناسبًا، وكود C++ يدوي حيث يلزم سلوك ديناميكي (مثل قائمة التحميلات ذاتية التحديث).
- الألوان والخطوط من 5.2 تُعرَّف مركزيًا في ملف QSS واحد (`themes/light.qss`, `themes/dark.qss`) — لا ألوان مكتوبة مباشرة (hardcoded) داخل كود الواجهة.
